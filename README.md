# Calculadora de custo de viagem

Página web que estima o custo de combustível de uma viagem usando autonomia do veículo (km/L), distância e preço por litro. Exercício de estudo de JavaScript.

## Stack
- HTML, CSS, JavaScript e Bootstrap 5

## Como executar
Abra `index.html` no navegador. Demo: https://cddppj.csb.app/.
